## 확인한 수정과 결과

- OpenAI 초안 작성에 `json_mode=True`를 연결해 JSON 출력 지정 누락을 수정했다. 출처·조건 검증은 유지한다.
- 1차 기존 질문 6번·8번에서 시스템별 문장 분리로 공통 서술이 빠지는 문제를 확인했다. 시스템 간 타임아웃과 공동 상태 질문의 전체 서술을 보존하고, 일반 상태 질문은 시스템별 알림 증상을 따로 검색하도록 수정했다.
- 최종 6번은 gateway·payments 모두 조사하고 network-timeout 근거를 수집한다. 최종 8번은 payments CPU와 cache 메모리 런북을 각각 확보한다.
- 01~08은 수집·보고서 검사 통과, 09는 미등록 대상 확인, 10은 일반 대화 응답을 확인했다. A2는 검증 수행이 아닌 미지원·무결과 처리의 통과다.
- 자동 테스트 81개 통과. 모든 화면의 수치·알림과 조회 대상·참고 원문은 상세 근거와 대조한다. 메모리/CPU 조치 조건 상태는 정책 코드가 계산하며 자동 실행하지 않는다.

## 해석 범위

동일한 10개 질문에 대한 기능 검증이며 전체 자연어 검색 정확도나 원인 확정을 보장하지 않는다. 이전 버전·Ollama 결과와 모델·데이터 변동 조건이 달라 지연·비용 개선율을 계산하지 않았다. UI 관측 시간은 자동화 호출 사이 대기까지 포함하므로 처리 시간으로 쓰지 않는다. 보고서의 비용 필드는 가상 단가 환산이며 실제 청구액이 아니다.

원본 10개 중 06의 기대 런북은 network-timeout이며 이번 설계에서는 두 시스템의 동일 호출 관계를 조사한다. 08은 cpu-spike·memory-leak를 기대한다. 기대값을 통과시키기 위해 질문을 바꾸지 않았다.
