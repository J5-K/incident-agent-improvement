localhost:8600의 실제 Ollama 백엔드 응답을 저장했다. 원본 캡처에는 화면 여백이 있고 슬라이드에는 보고서 부분을 확대해 사용했다. 캡처별 화면 내용 텍스트와 캡처목록.json을 함께 보관한다. 전체 10개 UI 회귀 검증을 완료했다는 의미는 아니다.

현재 캡처의 모니터링 수치는 CPU 90.1%, 메모리 54.5%다. 과거 대표 실행의 값·시간과 구분한다. 과거 실행 시간을 최신 캡처의 시간으로 표시하지 않는다.

## 발표 시 주의

MCP·LangSmith·의존성 주입은 제공된 기반 활용과 직접 개선을 구분한다. 노드 파일 분리는 새로운 전문 멀티 에이전트 서브그래프 구현이 아니다. 검증 통과는 원인 확정이나 실행 승인이 아니며, LLM-as-a-Judge도 아니다. 검색 범위 추출은 제한된 표현 규칙을 사용한다.
