# 개선 전 Vue 수동 테스트 결과 (2026-10-20)

## 수집 방법

- 원본 코드 수정 없이 localhost:8600 Vue 화면에서 실행.
- 각 독립 질문은 페이지 새로고침으로 새 대화 ID를 자동 생성.
- 01·10은 사용자 제공 캡처, 02~07은 Vue 실행에서 수집. 08·09는 사용자가 교체한 최신 완료 캡처로 갱신했다.
- 백엔드: Ollama / fast=qwen3:0.6b, quality=qwen3:8b.
- 실제 테스트 시각은 서로 다르며 모니터링 수치에는 샘플의 무작위 변동이 있음.
- 정밀 처리 시간·비용은 이 화면 캡처로 측정하지 않았음. 화면 성공 표시와 답변 정확성은 구분해야 함.

## 과제에 활용할 관점

1. 02는 단순히 RAG만 추가해도 해결된다고 단정할 수 없음. 먼저 장애 질문을 incident 경로로 보내야 함.
2. 03~06은 기존 키워드 기반 선택도 해당 샘플에서 작동함. 아직 RAG의 정확도 향상이 입증된 것은 아님.
3. 답변이 길이·번호 형식을 통과해도 근거에 없는 추론이 섞일 수 있어 근거 검증도 개선 후보임.
4. 개선 후 같은 질문·모델을 유지하고, 검색 자체 비교에는 고정된 알림 데이터를 사용해야 함.

## 파일 설명

- `01`~`10` PNG: 시나리오별 Vue 캡처.
- `화면기록.json`: 02~09 화면의 질문·진행 단계·답변·펼친 프롬프트 기록.
- `테스트질문10개.json`: 질문 목록과 시나리오 기대 매뉴얼. 정답의 절대 보장이 아닌 평가 설계용 기대값.
- 원본 소스 ZIP은 로컬 보관용이며 Git 저장소에는 포함하지 않는다. 소스 기준점은 Git 커밋으로 보존한다.

사용자 제공 01 질문 끝의 불필요한 기호 등은 캡처 원본 그대로 보존했다. 이 문서는 개선 전 관찰이며 개선 성과나 공식 정확도 점수를 주장하지 않는다.

## 수집 현황

총 10개 시나리오 모두 최종 답변 완료 캡처를 확보했다. 08·09는 초기 대기 관찰 이후 사용자가 교체한 완료 캡처를 기준으로 갱신했다. 완료는 정확성 합격을 뜻하지 않는다. 자동 API 테스트 결과와 이 Vue 실행 기록은 별개이며 혼합하지 않았다.

## 최신 캡처 반영

08·09의 숫자와 답변은 최신 PNG에서 사람이 확인해 전사했다. 초기 대기 상태의 자동 화면 텍스트를 최신 완료 상태의 원시 로그로 가장하지 않았다. 지연 시간은 측정하지 않아 수치로 보고하지 않는다.
