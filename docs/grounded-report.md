# 근거가 구분된 진단 보고서

최종 답변을 확인된 사실 / 원인 추정 / 권장 점검·조건부 조치 / 참고 출처로 분리했다.

- 수치는 모니터링 객체에서 직접 출력한다. 원본 경고는 현재 측정값과 분리하고 시점 미확인임을 표시한다.
- AI는 출처·단계·원인 가설 코드를 선택한다. 원인은 고정된 **가능성** 문장으로 출력하며 확정 사실로 표현하지 않는다.
- 매뉴얼 단계는 가져온 원문을 인용한다. 조건 미충족이면 권고 보류, 미검토 조건은 추가 확인으로 표시한다. 자동 실행은 없다.
- 모델이 CPU 증설/메모리 재시작 단계를 선택하지 않아도 검토된 수치 조건 대조를 별도로 표시한다.
- 참고 출처에 Tool 이름, 시스템명, Resource URI·서버를 표시한다. 내부 보고서 JSON에는 매뉴얼 해시도 보관한다.
- 검증 3회 실패 시 출처가 있는 사실만 제공한다. 미검증 원인·조치 문장은 출력하지 않는다.
- Vue에 검증 범위, 출처 수, 작성 시도 횟수를 표시한다. JSON 초안 토큰은 노출하지 않는다.
- `/chat` metadata.report에 구조화 보고서를 제공한다. SSE는 읽을 수 있는 최종 보고서와 진행 이벤트를 제공한다.

이는 의미 검색/RAG나 LLM-as-a-Judge가 아니다. 원인 가설이 참인지 판단하지 않으며, 매뉴얼 선택은 기존 키워드 규칙이다. 자연스러운 자유 서술의 폭을 줄여 수치·조건과 출처를 보존하는 선택이다. 추가 시계열·로그 없이 근본 원인을 확정하지 않는다.
